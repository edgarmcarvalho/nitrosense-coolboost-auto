First stable version. It can now be installed and updated with a PowerShell line that Windows doesn't block. Installing over an older version upgrades in place and keeps your settings.

### New
- **Install without being blocked by Windows.** Open PowerShell and paste one line (it's in the README). PowerShell downloads the latest release, checks its SHA-256 checksum and runs the installer, so SmartScreen and Smart App Control, which block browser downloads of unsigned files, never come into play. The installer window stays open, shows each step, and waits for you to press Enter.
- **Updates use the same method.** With **Check for updates automatically** turned on (it's off by default), a newer version shows up in the tray menu and in a notice. Clicking it opens the same visible installer window. Nothing is downloaded or installed unless you click.
- **Hardware check without downloading anything.** The optional, read-only check used by the compatibility form now also runs from a pasted PowerShell line.

### Download
- **PowerShell line (recommended):** see the README. It isn't blocked by Windows.
- `CoolBoostAuto-Setup-1.0.0.exe`: setup wizard. It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings > Apps*.
- `CoolBoostAuto-Scripts-1.0.0.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The setup and the zip aren't code-signed. SmartScreen may warn (**More info > Run anyway**), and **Smart App Control may block them**; if that happens, use the PowerShell line from the README.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam, Epic, GOG, Ubisoft Connect, EA app, Battle.net, Xbox / Game Pass, Amazon Games, Riot, itch.io, Rockstar and your own list), and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt. It never sets fan speeds or fan curves.
