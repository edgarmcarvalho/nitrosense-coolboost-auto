New tray menu, pause, and several fixes. Tested on the **Acer Nitro 5 AN515-55** (Windows 11, NitroSense 3.01); also reported working on the **AN515-57**. Installing over an older version upgrades in place and keeps your settings.

### New
- **Clearer tray menu:** the version and a status line at the top (what CoolBoost is doing and why), the rules at the top level, and a **Games** submenu to add a running app, ignore a game, or un-ignore one.
- **Pause automation:** stops all automatic switching until you resume. One-click switching still works. While paused, the tray icon shows an **amber pause badge**.
- **Start with Windows** can be switched on or off from the menu.
- **Exit stops everything:** when CoolBoost Auto is closed, the plug/unplug rules don't run either. CoolBoost stays as it is.
- **The tray icon changes only once the laptop confirms the switch**, so it always shows the real state.

### Fixes
- If you turned CoolBoost off mid-game outside the tray (for example in NitroSense) and it was already on when the game started, the automation turned it back on. It now leaves it off until the game closes.
- Pausing mid-game no longer confuses the game rule.
- Turning CoolBoost on by hand while on battery, then waking the laptop from sleep, could make plugging in turn CoolBoost on instead of restoring the state from before you unplugged.
- The game name was shown as a single letter when one game was running.
- Power state is read from the same source everywhere, with a short double-check, to avoid CoolBoost switching off by mistake.

### Download
- **`CoolBoostAuto-Setup-0.9.3.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings → Apps*.
- `CoolBoostAuto-Scripts-0.9.3.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info → Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam libraries, Rockstar, and your own list), and back when the game closes.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
