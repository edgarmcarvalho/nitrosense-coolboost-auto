Detects games from more stores. Installing over an older version upgrades in place and keeps your settings.

### New
- **More game stores are detected automatically:** **GOG**, **Ubisoft Connect**, **EA app**, **Battle.net**, the **Xbox app / Game Pass**, **Amazon Games**, **Riot Games** and **itch.io**, on top of Windows' game list, Steam, Epic Games, Rockstar and your own list. CoolBoost turns on while one of their games runs and goes back when it closes. Launchers themselves (for example the Riot client) don't count as a game.
- Games bought on Nuuvem are covered through the store they're activated on (Steam, Epic, Ubisoft Connect and so on). A DRM-free game in a custom folder can be added with **Games > Add a running app**.

Tested with simulated games for each store; if a game of yours isn't picked up, please tell me (the compatibility form on GitHub works for that too).

### Download
- **`CoolBoostAuto-Setup-0.9.7.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings > Apps*.
- `CoolBoostAuto-Scripts-0.9.7.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info > Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection, and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
