First public beta. Tested on an **Acer Nitro 5 AN515-55** (Windows 11, NitroSense 3.01). Please open an issue saying whether it works on your model.

### Download
- **`CoolBoostAuto-Setup-0.9.0.exe`**: setup wizard (recommended). It checks your laptop first and installs nothing if it isn't supported. Uninstall from *Settings → Apps*.
- `CoolBoostAuto-Scripts-0.9.0.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info → Run anyway**), and **Smart App Control blocks it**; if you have Smart App Control on, use the scripts zip. Free signing through the SignPath Foundation has been requested.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / leave as is.
- **On while gaming**, with automatic game detection (Windows' game list, Steam libraries, Rockstar, and your own list), and back when the game closes.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
- NitroSense never has to open, and its own setting stays in sync.
