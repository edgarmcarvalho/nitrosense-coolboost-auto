Second beta. Tested on an **Acer Nitro 5 AN515-55** (Windows 11, NitroSense 3.01). Installing it over v0.9.0 upgrades in place and keeps your settings.

### Changes
- **Fix: CoolBoost could keep turning off while plugged in.** The background task and the tray icon read "plugged in or on battery" from two different Windows sources. On some laptops these can disagree, so the background task could switch CoolBoost off while the gaming automation switched it back on. Both now use the same source, and the background task confirms the power state for a few seconds before acting.
- **Named CoolBoost Auto everywhere:** the Start menu shortcut, the installer and the tray tooltip. Upgrading removes the old "CoolBoost Tray" shortcut.
- **Both logs in the tray menu:** *Open log* now offers "Power and manual switching" and "Gaming automation". That makes it easier to send them when reporting a problem.
- Builds now syntax-check every script before compiling.

### Download
- **`CoolBoostAuto-Setup-0.9.1.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings → Apps*.
- `CoolBoostAuto-Scripts-0.9.1.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info → Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / leave as is.
- **On while gaming**, with automatic game detection (Windows' game list, Steam libraries, Rockstar, and your own list), and back when the game closes.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
