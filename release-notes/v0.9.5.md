Lighter and sturdier. Tested on the **Acer Nitro 5 AN515-55** (Windows 11, NitroSense 3.01). Installing over an older version upgrades in place and keeps your settings.

### Changes
- **Uses about half the CPU of 0.9.4.** CoolBoost's state is now read with a much faster method (it's checked several times a second), and the game check only looks up programs it hasn't seen yet.
- **On battery, games are checked every 15 s instead of every 4 s.** The game rule only acts when plugged in; plugging in triggers a check right away.
- **The on-screen notice widens to fit long game names**, up to a limit; past that, the name ends with "…".

### Fixes
- If the settings file was read at the moment it was being saved, the tray could briefly fall back to the default settings, and a menu change made at that moment could save the defaults over your other settings. It now keeps your last good settings, and the file is only read when it changes.

### Download
- **`CoolBoostAuto-Setup-0.9.5.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings → Apps*.
- `CoolBoostAuto-Scripts-0.9.5.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info → Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam libraries, Rockstar, and your own list), and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
