Faster switching. Tested on an **Acer Nitro 5 AN515-55** (Windows 11, NitroSense 3.01). Installing over an older version upgrades in place and keeps your settings.

### Changes
- **Instant manual toggle:** clicking the tray icon now changes the icon right away (under 0.1 s). CoolBoost itself switches in about half a second. If a switch ever fails, the icon corrects itself.
- **Faster automation:** after you plug in or unplug, CoolBoost switches in about 3 seconds instead of 6–8. The power state is still double-checked, now for 1 second instead of 5.

### Download
- **`CoolBoostAuto-Setup-0.9.2.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings → Apps*.
- `CoolBoostAuto-Scripts-0.9.2.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info → Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / leave as is.
- **On while gaming**, with automatic game detection (Windows' game list, Steam libraries, Rockstar, and your own list), and back when the game closes.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
