Adds an optional update notice, Epic Games detection and a compatibility report form. Installing over an older version upgrades in place and keeps your settings.

### New
- **Update notice (optional, off by default).** Turn on *Check for updates automatically* in the tray menu and CoolBoost Auto looks for a newer release about once a day and shows a notice; clicking it opens the releases page. *Check for updates now* does it once, on demand. It only notifies: it never downloads or installs anything. The only data sent is the standard request to GitHub for the latest release number.
- **Epic Games Store games are detected automatically**, alongside Windows' game list, Steam, Rockstar and your own list. (Tested with simulated Epic manifests; if a game of yours isn't picked up, please report it.)
- **Compatibility report form.** Using another Acer laptop? You can now tell me whether it works, using a short form on GitHub, with an optional read-only check script (`tools/hardware-check.ps1`). See the README.

### Under the hood
- The installer now carries proper version information (product name, version, company).
- Code-signing steps are prepared in the release workflow. Signing is not active yet, pending approval of a free open-source application to SignPath Foundation.

### Download
- **`CoolBoostAuto-Setup-0.9.6.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings > Apps*.
- `CoolBoostAuto-Scripts-0.9.6.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info > Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection, and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
