A tidier tray menu and a better installer download. Installing over an older version upgrades in place and keeps your settings.

### Changed
- **The tray menu is shorter.** The rarely used items moved into two submenus: **Settings** (Start with Windows, On-screen notice, Check for updates automatically, Check for updates now) and **Tools** (Open NitroSense, Open log). The rules you use every day (battery, plugged in, gaming, Games, Pause) stay at the top, with their checkmarks.
- **One log instead of two.** **Tools > Open log** now shows everything CoolBoost Auto did in a single list, in time order. Each line is tagged `[power]` (switching on power changes and by hand) or `[tray]` (gaming and updates), so it's easy to tell where it came from.
- **The PowerShell installer shows a progress bar** with the download size and speed.

### Download
- **PowerShell line (recommended):** see the README. It isn't blocked by Windows.
- `CoolBoostAuto-Setup-1.0.1.exe`: setup wizard. It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings > Apps*.
- `CoolBoostAuto-Scripts-1.0.1.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The setup and the zip aren't code-signed. SmartScreen may warn (**More info > Run anyway**), and **Smart App Control may block them**; if that happens, use the PowerShell line from the README.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam, Epic, GOG, Ubisoft Connect, EA app, Battle.net, Xbox / Game Pass, Amazon Games, Riot, itch.io, Rockstar and your own list), and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt. It never sets fan speeds or fan curves.
