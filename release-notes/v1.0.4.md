Two small fixes and a cleaner zip.

### Fixed
- **The one-line install no longer fails with "403 Forbidden".** GitHub limits anonymous requests per hour for each internet address, and shared or busy networks hit that limit. The installer and the "Check for updates" option now use a path that has no such limit.

### Changed
- **The zip now has a single `README.txt`** (English and Portuguese) with install, update and removal steps and what to do if something goes wrong. It opens cleanly in Notepad.

### Download
- **PowerShell line (recommended):** see the README. It isn't blocked by Windows.
- `CoolBoostAuto-Scripts-1.0.4.zip`: the same thing as plain PowerShell scripts.
- `SHA256SUMS.txt`: checksums.
