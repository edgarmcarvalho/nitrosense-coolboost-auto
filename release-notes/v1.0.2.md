A fix for low battery. Installing over an older version upgrades in place and keeps your settings.

### Fixed
- **Clicking the tray icon did nothing when the battery was at 20% or less.** At that level, Windows' battery saver holds back background tasks, so CoolBoost couldn't switch and gave no sign of it. Now CoolBoost Auto tells you ("CoolBoost can't change right now: Windows is limiting background tasks while the battery is low. Plug in the charger and try again") and drops the request, so nothing switches by surprise later. Plug in the charger and it works as usual.

### Download
- **PowerShell line (recommended):** see the README. It isn't blocked by Windows.
- `CoolBoostAuto-Setup-1.0.2.exe`: setup wizard. It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings > Apps*.
- `CoolBoostAuto-Scripts-1.0.2.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The setup and the zip aren't code-signed. SmartScreen may warn (**More info > Run anyway**), and **Smart App Control may block them**; if that happens, use the PowerShell line from the README.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam, Epic, GOG, Ubisoft Connect, EA app, Battle.net, Xbox / Game Pass, Amazon Games, Riot, itch.io, Rockstar and your own list), and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt. It never sets fan speeds or fan curves.
