Simpler to install and remove. Installing over an older version upgrades in place and keeps your settings.

### Changed
- **There is no setup `.exe` anymore.** Windows' protection (SmartScreen and Smart App Control) kept blocking it, and some antivirus programs flagged it. CoolBoost Auto is now installed with the PowerShell line from the README, which Windows doesn't block.
- **CoolBoost Auto now shows up in Windows Settings.** Remove it from *Settings > Apps > Installed apps > CoolBoost Auto > Uninstall*, like any other program. Or use the new one-line uninstall command in the README.
- **The zip now has an `INSTALL.txt`** with step-by-step instructions (English and Portuguese), for anyone who downloads the zip and gets lost.

### Download
- **PowerShell line (recommended):** see the README. It isn't blocked by Windows.
- `CoolBoostAuto-Scripts-1.0.3.zip`: the same thing as plain PowerShell scripts, with an `INSTALL.txt` inside.
- `SHA256SUMS.txt`: checksums.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam, Epic, GOG, Ubisoft Connect, EA app, Battle.net, Xbox / Game Pass, Amazon Games, Riot, itch.io, Rockstar and your own list), and back when the game closes.
- An **on-screen notice** when CoolBoost switches, saying why.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt. It never sets fan speeds or fan curves.
