An on-screen notice when CoolBoost switches. Tested on the **Acer Nitro 5 AN515-55** (Windows 11, NitroSense 3.01). Installing over an older version upgrades in place and keeps your settings.

### New
- **On-screen notice:** every time CoolBoost turns on or off, a small notice rises from behind the taskbar for about 3 seconds, in the style of Windows 11's own volume and airplane-mode notices. It never takes focus and clicks go through it.
  - When CoolBoost Auto made the switch, it says why: *unplugged*, *plugged in*, *gaming: (the game)*, *game closed*, *automation resumed*, or *manual, until the game closes*.
  - When you switched it yourself (the tray icon, NitroSense, a hotkey), it shows just the new state.
  - On by default. Turn it off with **On-screen notice** in the tray menu.

### Changes
- The tray notices changes made outside it (NitroSense, plugging in or out) faster: it now checks every 0.5 s instead of 1.5 s.

### Download
- **`CoolBoostAuto-Setup-0.9.4.exe`**: setup wizard (recommended). It checks compatibility first (CoolBoost interface + NitroSense) and installs nothing if your laptop isn't supported. Uninstall from *Settings → Apps*.
- `CoolBoostAuto-Scripts-0.9.4.zip`: the same thing as plain PowerShell scripts (`install.ps1` / `uninstall.ps1`).
- `SHA256SUMS.txt`: checksums.

> The installer isn't code-signed yet. SmartScreen may warn (**More info → Run anyway**), and **Smart App Control may block it**; if that happens, use the scripts zip.

### What it does
CoolBoost Auto switches CoolBoost on and off automatically, based on context:
- **Off on battery**, so the fans don't drain it.
- A rule for **when you plug in**: restore / always on / always off / keep the battery state.
- **On while gaming**, with automatic game detection (Windows' game list, Steam libraries, Rockstar, and your own list), and back when the game closes.

Plus manual control when you want it: **one click** on the NitroSense-style tray icon toggles CoolBoost, with no admin prompt.
